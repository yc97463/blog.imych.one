很快樂耶！與其說是來比賽，不如說是我們三五好友聚在一起開同學會，平常在各自的學校悶壞了，到第一天下午我們還在慵懶地享受著這份幸福。

後記：最近 CloudMosa 傳來通知，要提供額外的加碼獎金，並且準備安排一趟去他們的辦公室，真好！我們預計在期中考後聚聚，之後再開一篇文章分享辦公室遊記。

# 中秋騎上武嶺

中秋連假臨時起意上武嶺，打算試試看我的「買菜車（115c.c.）」騎上合歡山到底會不會半路拋錨（油耗、效能），找了朋帶我騎騎看，順便讓他背一些備用的汽油在車上。

先說結論，全程 413 公里，買菜車效能其實超夠，騎長途更是省油許多。在山裡悠哉真的蠻舒服的 (((o(ﾟ▽ﾟ)o)))！

山路基本上 40kph 順順騎，引擎隨著騎乘時間越久，運作的震動會越趨於平穩。我跟朋原本的策略是，如果車車到海拔高的地方催不動，那就來拔空濾 ~~讓他大口呼吸~~。我的油箱裝到滿才大概三公升出頭 TT，搭配城鄉通勤的油耗，預估中間要一直補加油。

平常在城鄉之間通勤大概落在 3 公升的油跑 40 公里，停紅燈跟重新起步太耗油啦，一次綠燈的號誌週期大約 60 秒。

我們帶了兩個寶特瓶（1.3L + 1.8L），在太魯閣山腳下的[中油太魯閣站](https://maps.app.goo.gl/hCVHiiHsHm6GZTDG8)把油加滿就上山。途中大概遇到兩三次加油站，上山後每次加大概都不到 1 公升。連續爬坡這麼長一段路途居然不如預期中耗油，真令人感到驚訝的說。

抵達武嶺後，我們去爬北峰步道，不過只爬了前段就下來（好累xd），兩個胸破的跑去高山登山超鬧，感覺吸不太到氧氣而且很疲累🥵。

{{< figure src="r2:now/20261022/20260927-HehuanNorthPeakTrail.jpeg" title="北峰步道，群山、綠坡與湛藍高山水池" >}}

這時我的腦袋又不安分了：

- 我：欸，離宜蘭很近了耶，要不要吃奶凍捲。
- 朋：好啊！

我們就出發了，完全沒想到當時已經下午兩點，下山還要再騎四個小時多💀，中途在梨山山區繞了不少時間，到平地已經天暗了。

他騎的是 KTM，帶彎下山速度是真的快。從宜蘭回花蓮，有段是我想騎蘇花改他騎舊蘇花，我在蘇花改裡定速 50kph 出來，他早就繞完山路出來在等我了哈哈哈。

# 大五上生存報告

開學一個多月，又開始懷疑人生了（笑不出來）。

上個學期好不容易從課業的煩惱中跳脫出來，重新找回一點讀書的樂趣，這學期卻好像又陷回去了。最近上課時，聽完老師介紹可怕的考試範圍與規矩（這學期硬課只有大刀新老師開），接著又聽到「但你不用太擔心」之類的安慰，實在有點哭笑不得。幾次坐在教室裡，很想直接離開，覺得自己怎麼又回到了這種生活。

```
缺的課都在上學期居多，大五上的課程分布：
SSS: 高微、微分方程，兩門都只有板書授課 :(，沒有指定教材 死透
SS: 基礎機率、複變函數論，可能需要通靈讀書
A 基礎練習: 代數一、線性代數、作業系統
B 躺著過: 敝系專題
```

最荒謬的是，連期中考都還沒考完，我就已經焦慮到在跟朋討論讀到大六的事情了💀。

前幾天跟朋聊到，才發現自己對於延畢的焦慮，已經不只是多花半年、一年讀書這麼簡單。如果真的再多留半年，可能就得開始自己負擔生活費了。原本還能任性地說「先讀讀看，讀不完再說」，現在卻不得不開始考慮這些很現實的問題。

回頭想想，去年試著放下那些讓自己煩惱的事情，反而讀得挺開心的，也順利把大部分科目都修過了。當時以為自己終於找到和大學生活相處的方法，沒想到只是暫時逃過一劫（？）。

不過說來也挺感慨的，以前在[高中時寫過一篇文章](/memorable-educator-in-high-school/)，記錄老師如何理解、包容我不願意把時間全部投入學科考試，而是選擇去寫程式、做專題，探索自己感興趣的事情。那時候真的很討厭為了考試而讀書，也很慶幸遇到了願意讓我照著自己的步調學習的老師。

但也因為這樣，過去幾年其實有不少學科基礎與讀書習慣，是我一直沒有好好建立起來的。到了大學，尤其是最近這兩年，反而像是被課業推著走，慢慢學會怎麼讀書、怎麼面對自己不擅長的內容，怎麼把那些以前沒學好的東西一點一點補回來。

想想還真是奇妙。高中時好不容易爭取到不被學科綁住的自由，幾年後卻又得回過頭來，學習如何當一個普通的學生。

恩～倒也不是後悔當時的選擇。如果沒有那段自由探索的時間，大概也不會有現在這些開發經驗，更不會認識這麼多人、經歷這麼多有趣的事情。 **只是這些當年沒有面對的部分，終究還是以另一種形式出現在生活裡。**
